# 📘 2º DAM – Desarrollo de Aplicaciones Multiplataforma

Este repositorio reúne **ejercicios, prácticas, ejemplos y contenido organizado por módulos** correspondiente al segundo curso del ciclo formativo de **Desarrollo de Aplicaciones Multiplataforma (DAM)**.

---

## 🧱 Estructura del Repositorio

El contenido está organizado por carpetas según las asignaturas del segundo curso:

### 📂 Módulos

- **Acceso a Datos**  
  (Acceso y manipulación de información desde bases de datos)

- **Desarrollo de Interfaces**  
  (Creación y diseño de interfaces de usuario)

- **Modelo-Vista-Controlador**  
  (Arquitectura de software y separación de responsabilidades)

- **Programación Multimedia y Dispositivos Móviles**  
  (Aplicaciones multimedia y desarrollo móvil)

- **Programación de Procesos y Servicios**  
  (Servicios, hilos, gestión de procesos)

- **Sistemas de Gestión Empresarial**  
  (Sistemas empresariales y aplicaciones de gestión)

---

Este repositorio incluye ejemplos y código en diferentes tecnologías utilizadas en el curso:

*(La mezcla de lenguajes refleja la naturaleza práctica y diversa de los ejercicios del ciclo.)*

## 📌 Cómo Usar este Repositorio

1. Explora cada carpeta para ver ejercicios y prácticas por módulo.  
2. Entra en cada proyecto para compilar o ejecutar el código según el lenguaje o herramienta utilizada.  
3. La mayoría de carpetas pueden contener recursos, guiones, código fuente o ejemplos de aplicación real.
